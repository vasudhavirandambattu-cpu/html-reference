What is HTML

HTML stands for HyperText Markup Language. It is the standard markup language used to create and design web pages. HTML defines the structure of a webpage by using different elements called tags. These tags tell the browser how to display text, images, videos, tables, forms, links, and other content.

Definition

HTML is not a programming language; it is a markup language. It uses tags to organize content into headings, paragraphs, lists, tables, images, and other webpage components. Every website on the Internet uses HTML as its foundation.

Uses of HTML

  • Creates the structure of web pages.
  • Adds headings and paragraphs.
  • Displays images, audio, and videos.
  • Creates hyperlinks between web pages.
  • Designs forms for user input.
  • Creates tables and lists.
  • Works with CSS for styling and JavaScript for interactivity.

Features of HTML

HTML (HyperText Markup Language) is the standard language used to create web pages. It is simple to learn, platform-independent, and supported by all modern web browsers. HTML provides the basic structure of every webpage and works together with CSS and JavaScript to create attractive and interactive websites.

Key Features

  • Easy to learn and use.
  • Platform independent.
  • Supports multimedia (images, audio, video).
  • Allows hyperlinks between pages.
  • Works with CSS and JavaScript.
  • Supports forms and tables.
  • Search engine friendly.

Advantages

  • Free and open standard.
  • Supported by every browser.
  • Lightweight and fast.
  • Easy to maintain.

Basic Structure of HTML

Every HTML document follows a standard structure. The browser reads the document from top to bottom and displays the webpage accordingly.

Main Parts of an HTML Document

  • <!DOCTYPE html> - Declares HTML5.
  • <html> - Root element.
  • <head> - Contains title, meta tags and links.
  • <title> - Displays page title.
  • <body> - Contains visible webpage content.

HTML Elements & Tags

HTML elements are the building blocks of a webpage. Most HTML elements have an opening tag, content, and a closing tag.

Common HTML Tags

  • <h1> to <h6> - Headings
  • <p> - Paragraph
  • <a> - Hyperlink
  • <img> - Image
  • <table> - Table
  • <ul> and <ol> - Lists
  • <form> - Form
  • <div> - Division

Types of Elements

  • Block Elements
  • Inline Elements
  • Semantic Elements

HTML Attributes

Attributes provide additional information about HTML elements. They are always written inside the opening tag.

Common HTML Attributes

Attribute Purpose
href Specifies the destination of a link.
src Specifies the image source.
alt Displays alternate text if the image is unavailable.
id Gives a unique identifier.
class Groups multiple elements for CSS.
style Adds inline CSS.
title Shows a tooltip on hover.

Benefits of Attributes

  • Provide additional information.
  • Help in styling with CSS.
  • Used by JavaScript.
  • Improve accessibility.
